# 计数系统使用说明

## 一、定义计数

在使用计数之前，**必须先**在 `Assets/Scripts/Data/CountDefinition.cs` 文件中定义计数名称。

### 定义方法

打开 `CountDefinition.cs`，在 `DefinedCounts` 集合中添加计数名称：

```csharp
public static readonly HashSet<string> DefinedCounts = new HashSet<string>
{
    "噩梦次数",      // 示例：噩梦次数

    // 在此添加更多计数...
};
```

**重要**：未在 `CountDefinition.cs` 中定义的计数无法在剧情编辑器中使用，使用时会报错。

---

## 二、格式说明

### 1. 判断一段剧情该不该触发（段落条件）

**位置**：在剧情图的段落节点中，设置 `ParagraphCondition` 字段

**格式**：使用计数条件判断，格式为：`计数_计数名_操作符值`

**支持的操作符**：
- `==` 等于
- `>=` 大于等于
- `<=` 小于等于
- `>` 大于
- `<` 小于

**示例**：
```
计数_噩梦次数_==1      // 当噩梦次数等于1时触发
计数_噩梦次数_>=3      // 当噩梦次数大于等于3时触发
计数_噩梦次数_<=2      // 当噩梦次数小于等于2时触发
计数_噩梦次数_>1       // 当噩梦次数大于1时触发
计数_噩梦次数_<5       // 当噩梦次数小于5时触发
```

**注意**：
- 计数名必须在 `CountDefinition.cs` 中定义
- 如果使用未定义的计数，会在控制台输出错误信息
- 格式必须严格按照 `计数_计数名_操作符值` 的格式

---

### 2. 判断一段剧情该走哪个分支（分支条件）

**位置**：在剧情图的分支节点（BranchCondition）中，设置分支端口的名称

**格式**：与段落条件相同，格式为：`计数_计数名_操作符值`

**示例**：
```
计数_噩梦次数_==1      // 当噩梦次数等于1时走此分支
计数_噩梦次数_==2      // 当噩梦次数等于2时走此分支
计数_噩梦次数_>=3      // 当噩梦次数大于等于3时走此分支
```

**注意**：
- 计数名必须在 `CountDefinition.cs` 中定义
- 如果使用未定义的计数，会在控制台输出错误信息，该分支将不会触发
- 格式必须严格按照 `计数_计数名_操作符值` 的格式

---

### 3. 修改某个计数的值（对话效果）

**位置**：在剧情图的对话节点中，设置 `TriggerMessageEffect` 字段

**格式**：`计数_计数名_操作值`

**支持的操作**：
- `+数字`：增加计数（如：`+1`、`+2`）
- `-数字`：减少计数（如：`-1`、`-2`）
- `=数字`：设置计数（如：`=1`、`=0`）

**示例**：
```
计数_噩梦次数_+1     // 噩梦次数增加1
计数_噩梦次数_-1     // 噩梦次数减少1
计数_噩梦次数_=1     // 设置噩梦次数为1
计数_噩梦次数_=0     // 重置噩梦次数为0
```

**多个效果**：可以用分号 `;` 分隔多个效果：
```
计数_噩梦次数_+1;音效_音效名_true
```

**注意**：
- 计数名必须在 `CountDefinition.cs` 中定义
- 如果使用未定义的计数或格式错误，会在控制台输出错误信息，包含：
  - 错误类型（计数未定义/格式错误）
  - 计数名称
  - 错误位置信息

---

## 三、查看计数

### 方法1：在代码中查看

```csharp
// 获取单个计数值
int value = CountManager.Instance.GetCount("噩梦次数");

// 获取所有计数
Dictionary<string, int> allCounts = CountManager.Instance.GetAllCounts();
foreach (var kvp in allCounts)
{
    Debug.Log($"{kvp.Key} = {kvp.Value}");
}
```

### 方法2：在编辑器中查看（调试用）

在 Unity 编辑器中，可以在控制台调用：
```csharp
CountManager.Instance.PrintAllCounts();
```

这会打印所有计数的当前值到控制台。

## 四、错误处理

### 错误类型

1. **计数未定义错误**
   - 错误信息格式：`[计数效果错误] 计数 "计数名" 未在 CountDefinition.cs 中定义！`
   - 解决方法：在 `CountDefinition.cs` 中添加该计数名称

2. **格式错误**
   - 错误信息格式：`[计数效果格式错误] 操作值格式不正确：...`
   - 解决方法：检查格式是否正确，应使用 `+数字`、`-数字` 或 `=数字` 格式

3. **分支条件错误**
   - 错误信息格式：`[分支条件错误] 计数 "计数名" 未在 CountDefinition.cs 中定义！条件："条件字符串"`
   - 解决方法：在 `CountDefinition.cs` 中添加该计数名称

### 错误位置

所有错误都会在 Unity 控制台中显示，包含：
- 错误类型
- 计数名称
- 条件字符串（如果是分支条件）
- 操作值（如果是计数效果）

## 五、完整示例

### 示例1：使用计数控制剧情分支

1. **定义计数**（在 `CountDefinition.cs` 中）：
```csharp
"噩梦次数"
```

2. **设置初始值**（在对话效果中）：
```
计数_噩梦次数_=0
```

3. **增加计数**（在对话效果中）：
```
计数_噩梦次数_+1
```

4. **判断分支**（在分支节点中）：
- 分支1：`计数_噩梦次数_==1`
- 分支2：`计数_噩梦次数_==2`
- 分支3：`计数_噩梦次数_>=3`

### 示例2：使用计数触发段落

1. **定义计数**（在 `CountDefinition.cs` 中）：
```csharp
"探索次数"
```

2. **设置段落条件**（在段落节点中）：
```
计数_探索次数_>=5
```

3. **当探索次数达到5次时，该段落会自动触发**

---

## 六、注意事项

1. **必须先定义后使用**：所有计数必须在 `CountDefinition.cs` 中定义后才能使用
2. **计数会保存到存档**：所有计数值会自动保存到存档中
3. **计数名区分大小写**：计数名是区分大小写的，请保持一致
4. **未定义的计数不会生效**：使用未定义的计数时，操作会被忽略并报错
5. **格式必须正确**：格式错误会导致操作失败并报错
